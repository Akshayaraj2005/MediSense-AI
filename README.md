# MediSense AI – Healthcare Review Intelligence System

An NLP and Machine Learning based project that analyzes hospital patient feedback and classifies reviews into Positive and Negative sentiment.

## Project Overview

MediSense AI is a healthcare review intelligence system designed to understand patient feedback using Natural Language Processing (NLP) and Machine Learning.

The project uses text preprocessing and machine learning algorithms to identify the sentiment expressed in hospital reviews.

## Project Objectives

- Analyze hospital patient feedback.
- Clean and preprocess text data.
- Convert text into numerical features using TF-IDF.
- Classify reviews into positive and negative sentiments.
- Build a simple web application for sentiment prediction.

## Machine Learning

This project is a Supervised Binary Classification problem.

Sentiment labels:

- 0 – Negative
- 1 – Positive

Algorithms explored:
- Logistic Regression
- Naive Bayes
- Linear Support Vector Machine (SVM)

## Project Files

- `MediSense_AI.ipynb` – Data analysis, preprocessing and model development.
- `app.py` – Web application.
- `medisense_model.pkl` – Saved machine learning model.
- `tfidf_vectorizer.pkl` – Saved TF-IDF vectorizer.

## Dataset

The project uses hospital patient feedback data containing review text, sentiment labels and ratings.

The dataset file is not included in this public repository. It is kept locally because patient feedback may contain sensitive information.
